# Grupo 0x06
Trabajo práctico máquina virtual - Parte II (2C 2025)<br/>
Fundamentos de la Arquitectura de Computadoras <br/>
Universidad Nacional de Mar del Plata

## Descripción
Aplicación, en lenguaje de programación java, que
emula la ejecución de un programa en el lenguaje máquina de una computadora. El programa a ejecutar se encuentra previamente escrito en el lenguaje Assembler de la máquina virtual y traducido a lenguaje máquina con el programa traductor (vmt) que provee la cátedra.
